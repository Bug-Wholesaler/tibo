# Day 02 · YPod 🛸

平时写代码经常同时开着 Claude Code、Codex 或者 Antigravity 让它们在后台自己跑。但切出去看文献或者摸会儿鱼的时候，老是心里没底：不知道它是在认真改代码、卡死循环了、额度快见底了，还是偷偷把不该改的文件给删了。

所以 Day 2 搓了个叫 **YPod** 的桌面置顶小悬浮舱，专门挂在屏幕角落盯这些 Coding Agent 干活。

---

## 里面能看啥

- **算力、首字响应 (TTFT) 与剩余额度**：实时看当前对话烧了多少 Token、缓存命中省了多少；每一步等模型吐出首字的秒数（`⏱️ 首字 X.Xs`）；还能直接看**上下文容量水位**和**模型剩余配额百分比**（支持读取 Antigravity 本地语言服务实时剩余额度与重置倒计时、Codex 5h 窗口限流及自定义 API 每日预算水位）。
- **动刀雷达 & 迷你 Diff**：它改了哪几个文件、加了几行删了几行，不用切回编辑器，直接在小窗里点开就能看红绿 Diff，左键一键跳回对应源码文件。
- **死循环与撞车提醒**：要是在同一个报错上反复横跳，或者两个窗口同时改同一个文件，小窗会直接亮灯提醒；高危命令（比如删库、强推分支）也可以配置 Hook 先挂起等你点放行。
- **贴边隐身**：嫌挡视线的话，拖到屏幕左/右/上边缘就会自动吸住缩成一条窄光条，鼠标移过去或者按 `Alt + Shift + Y` 随时弹出来。

---

## 怎么跑起来

### 方法 1：直接双击启动（Windows）
本地装了 Node.js 的话，直接双击目录里的 **`启动YPod.bat`** 就能跑。

如果自己打过绿色包，也可以直接双击：
```text
dist/YPod-Portable/YPod.exe
```

### 方法 2：命令行运行
```bash
cd day2
npm install
npm start
```

需要打包独立免安装目录（输出到 `dist/YPod-Portable/`）：
```bash
npm run dist
```

跑单测：
```bash
npm test
```

## 目录说明

- `main.js` / `preload.js`：Electron 悬浮窗主进程与屏幕边缘磁吸逻辑
- `src/log-watcher.js`：本地会话日志监听、Token 统计、首字耗时 (TTFT) 与本地配额探针
- `src/ai-interpreter.js`：改动文件提取、代码 Diff 解析与死循环检测
- `src/hook-bridge.js`：可选的高危命令拦截桥接脚本（自动释放至 `~/.ypod/hook-bridge.js`）
- `ui/index.html`：悬浮舱界面（内置 4 套配色主题，支持一键切换）

# Day 03 · 学堂 × 雨课堂 合一工作台

这学期好几门课都是两边同时开：作业和参考书扔在网络学堂，上课 PPT、随堂小测和课堂回放又全发在雨课堂。每次找一份资料或者核对这周还有几个 DDL，都得在两个画风完全不一样的网站之间来回切标签页翻半天。

干脆搓了个全屏覆盖式的浏览器扩展，打开任意一边的主页，直接把两个平台焊成同一个清爽的双栏工作台。

## 它能干嘛

- **全屏覆盖原页面，一键切回**：打开网络学堂或雨课堂主页时自动铺满双栏工作台；想看原网页点右上角红色「返回原网页」秒退回，或者随时按 `Alt + K` 呼出/收起。跳去具体的交作业页、看课件页时会自动收成右下角小胶囊，不挡正常操作。
- **同名课程自动合体**：自动识别两边名字带全半角括号、学期前缀或班级后缀的同一门课，合并成同一张课程卡片。万一遇到两边起名差太多的课，点顶栏「课程配对」手动绑一下就行。
- **跨平台 DDL 倒计时雷达**：把学堂未交作业和雨课堂未做测验混排到同一个倒计时列表里，支持切到「已交核对」确认有没有漏交。
- **课堂回放速查 + 正在直播置顶 + 倍速画中画增强**：把平时藏在雨课堂日志深处的上课实录和学堂录播视频单独拎出来做成一级入口，遇到正在直播的课自动在顶栏标红置顶、一键直达直播间；回放和视频页自动挂上悬浮增强条，支持点击数字自定义输入 `0.5x ~ 16x` 倍速自动记忆（快捷键 `[` / `]` 调速，进入直播教室时自动切回原生速率防卡顿）和一键「📺 画中画」小窗悬浮记笔记。
- **课件、文件与带图公告一处速览**：在课程卡片里直接展开看两边的作业、课堂回放、PPT 课件、课程文件和公告；学堂文件支持直链下载，带插图或座位表图片的公告支持卡片内直接展开或弹窗看高清大图。
- **免输密码复用浏览器登录态**：不在扩展里填账号密码，平时浏览器登过这两个网站就能直接同步缓存在本地。

## 怎么装到浏览器里

支持 Chrome、Edge、Arc 等 Chromium 内核浏览器：

1. 直接下载打好包的 [`course-hub-extension.zip`](https://github.com/Bug-Wholesaler/yttrium/raw/main/day3/dist/course-hub-extension.zip) 解压到本地任意文件夹（如果已经 clone 了整个 [`yttrium`](https://github.com/Bug-Wholesaler/yttrium) 仓库，直接用 `day3` 目录就行）。
2. 打开浏览器的扩展管理页（Chrome 地址栏输 `chrome://extensions`，Edge 输 `edge://extensions`）。
3. 打开右上角的 **「开发者模式」** 开关。
4. 点击左上角 **「加载已解压的扩展程序」**，选中刚刚解压出来的文件夹（里面能直接看到 `manifest.json` 的那一层）。
5. 先确保浏览器里已经正常登录过网络学堂和雨课堂，刷新一下任意一边的主页，全屏工作台就会自动弹出来同步数据了。

## 本地验证与重新打包

```bash
cd day3
npm test
npm run pack
```

## 目录结构

- `manifest.json`：Manifest V3 扩展配置
- `core.js`：课程名归一化、双端自动匹配与 DDL 聚合引擎
- `background.js`：跨站同步与本地缓存后台服务
- `content.js`：全屏 Shadow DOM 覆盖式双栏前端与悬浮胶囊入口
- `player-rate-core.js` / `player-enhancer.js`：回放与视频页倍速记忆、直播流速率保护与画中画小窗悬浮条
- `popup.html` / `popup.js`：浏览器右上角图标速览弹窗
- `dist/course-hub-extension.zip`：解压即用的纯净扩展包

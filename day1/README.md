## 2. 四大核心升级特性

1. **纯粹清爽亮色风格**：
   - 摒弃复杂暗黑主题切换，直接采用适合小红书原生信息流审美的清爽亮色调（干净白卡、薄荷绿「已交作业」、奶茶暖橙「断更请客」、浅灰「未到日期」）。
2. **对接真实北京时间（UTC+8）**：
   - 顶部实时跳动显示北京时间与当前挑战进度（`Day XX / 28`）；
   - 28 宫格自动根据 `startDate: "2026-11-10"` 推算并展示每一格对应的日历日期（`11/10` ~ `12/07`）。
3. **博主单方控制状态 + 自动时间对齐（访客无法乱点篡改）**：
   - 格子的点亮与否不再由访问的粉丝点击决定，而是由 [`data.js`](file:///d:/university/tibo/day1/data.js) 中的 `status` 字段与真实时间共同决定：
     - `"done"`：显示清爽绿 `🚀 作品直达`；
     - `"reset"`：显示奶茶橙 `🧋 中奖公示`；
     - `"auto"`：未到当天日期时自动锁定为 `🔒 未到日期`；到达当天日期时自动显示 `⏳ 今日手搓中`。
4. **已解锁格子再次点击跳转 GitHub/下载，断更点击展示中奖用户图片**：
   - **已交作业（`done`）**：访客点击选中后，底部显示详情与按钮；**再次点击该格子**直接弹出「作品传送门」，可一键跳转对应的 `githubUrl`（GitHub 源码）或 `downloadUrl`（下载/体验链接）；
   - **触发断更（`reset`）**：访客点击橙色断更格子（或底部解锁的黄色横幅）时，直接弹出「断更奶茶锦鲤公示」窗口，展示存放在 `day1/images/` 下的**评论区抽中用户截图**。

## 3. 博主日常维护指南（每天仅需 10 秒）

- **平时日更交作业**：打开 [`day1/data.js`](file:///d:/university/tibo/day1/data.js)（或直接让 AI 帮你改），把当天对应的 `status` 改为 `"done"`，填上 `title`、`githubUrl` 和 `downloadUrl`。
- **万一断更抽奶茶**：把抽中的评论区读者截图放进 [`day1/images/`](file:///d:/university/tibo/day1/images/) 目录（如 `day3-winner.png`），在 `data.js` 中把当天 `status` 改为 `"reset"`，`winnerImage` 填 `"./images/day3-winner.png"`。
- **本地截图与录 Live 图**：本地双击 [`打开护茶监控台.bat`](file:///d:/university/tibo/day1/打开护茶监控台.bat) 打开时，顶部会自动出现「🛠️ 博主截图与预览台」（线上访客访问时自动隐藏），支持一键开启 **3:4 / 4:3 纯净截图模式** 与 **Live 图点亮演示模式**。

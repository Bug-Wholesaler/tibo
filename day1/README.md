# Day 01 · 28天护茶监控台 🧋

五道口某天坑在读，给自己立了个 **28 天日更手搓小工具** 的 Flag：  
每天利用实验搬砖的间隙搓一个解决日常怪痛点的小玩意儿，断更一天就在评论区抽一个人请喝奶茶。

结果立完 Flag 的第一天就差点被实验卡死。为了保住第一杯奶茶，干脆先手搓了这个用来监督我自己日更的看板网站——**用「监控不断更的网站」来充当第一天的更新**，四舍五入也算合理卡 Bug 交上作业了。

---

### 这是干嘛的？

这就是接下来 28 天的实时打卡大本营（在线看板：<https://yttrium-28days.pages.dev/>），直接跟真实日历时间对齐：

- **🚀 绿色格子（已交作业）**：说明当天顺利苟住了。点一下看当天搓了什么，**再点一下格子（或者点底部的按钮）就能直接跳到那天小工具的 GitHub 源码或下载链接**。
- **🧋 橙色格子（断更请客）**：如果哪天实验翻车或者赶 DDL 没更新，格子就会变橙色。点开可以直接看那天从评论区抽出来的奶茶锦鲤截图。
- **⏳ 蓝色 / 🔒 灰色格子**：当天正在手搓中，或者日子还没到。

---

### 文件说明

纯静态原生 HTML + CSS + JS 写的，没引任何乱七八糟的框架，打开就能跑：

- `index.html`：看板主页面
- `data.js`：每天的打卡状态、一句话简介和作品跳转链接都在这里维护
- `images/`：万一哪天真断更了，用来放评论区中奖读者的截图

如果你也想给自己立个类似的日更 Flag，直接把这几个文件拷走，改一下 `data.js` 里的 `startDate`（起始日期）和标题，随便丢到 Cloudflare Pages 或 GitHub Pages 就能直接用。
